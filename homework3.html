Toy ECC encryption, Caesar cipher, and attacks on restricted key spaces

1. Toy scheme based on secp256k1

The receiver selects a private key d and computes the public key Q = dG. For each encryption, the sender selects an ephemeral key k, publishes C1 = kG, and computes the shared point S = kQ. A SHA-256 counter-mode keystream derived from S is XORed with the UTF-8 message. The receiver computes the same point as dC1 and reverses the XOR.

Important: this is an educational hybrid construction, not a production cryptosystem. It intentionally uses a small private-key range and does not authenticate the ciphertext.

2. Caesar cipher

Each letter is shifted by a fixed key in the alphabet. Decryption applies the opposite shift. Non-letter characters are preserved.

3. Statistical cryptanalysis of Caesar

The attack tries all 26 shifts and scores each candidate with a chi-squared comparison against expected English letter frequencies. Lower scores indicate a closer statistical match.

4. Attack on the restricted ECC private-key space

The attack enumerates candidate private keys and compares each candidate public point dG with the known public key Q. Once d is recovered, it computes dC1 and decrypts the ciphertext. This is feasible only because the experiment deliberately restricts d.

5. Comparison and discussion

Encryption and decryption

Caesar substitutes every letter using one repeated shift, and decryption subtracts that shift. The toy ECC scheme uses a key pair and a fresh ephemeral scalar: both parties derive the same elliptic-curve shared point, then use it to mask the message.

Key spaces

Caesar has only 26 possible shifts, so exhaustive search is immediate. In this experiment the ECC private key is also deliberately small, making exhaustive search possible. Proper secp256k1 private keys range over approximately 2256 possibilities, so the same enumeration method is not practical.

Statistical properties

Caesar preserves letter frequencies exactly, merely relabelling letters; this enables language-frequency attacks. The ECC-based hybrid scheme masks encoded bytes with a hash-derived keystream, so the original single-letter distribution is not directly preserved. Its ciphertext also changes when k changes.

Different weaknesses

The Caesar attack exploits language redundancy and the cipher's fixed substitution structure. The ECC attack implemented here does not exploit letter statistics; it exploits the artificially restricted private-key space. Separately, the toy construction lacks authentication, so it should not be treated as a replacement for a standard authenticated encryption scheme.

Limitations of frequency analysis

Short texts fluctuate strongly from normal language frequencies. Names, technical vocabulary, unusual genres, spelling variation, and a corpus in the wrong language can all rank an incorrect key first. Exhaustive search always lists all 26 Caesar candidates, while chi-squared or n-gram scoring helps automate which candidate looks most plausible.
