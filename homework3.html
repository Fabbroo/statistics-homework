How the Toy ECC Scheme Works

This toy cryptographic scheme uses the elliptic curve y² = x³ + 7 (mod 17) and the generator G = (1,5).

  1. The receiver chooses a private key k.
  2. The public key is computed as Q = kG.
  3. The x-coordinate of Q is used as a secret value.
  4. Each plaintext character is XORed with the secret value.
  5. XORing again with the same secret recovers the original text.

This construction is intentionally simplified for educational purposes and must not be considered secure.
