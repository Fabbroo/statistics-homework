Toy ECC Encryption Scheme

This toy scheme imitates the idea behind ECIES.

Encryption

  1. The receiver chooses a private key d.
  2. The public key is Q = dG.
  3. The sender generates a random ephemeral key r.
  4. The sender computes R = rG.
  5. The shared secret is S = rQ.
  6. The x-coordinate of S is used as a symmetric key.
  7. The message is encrypted using XOR.

Decryption

  1. The receiver receives R and the ciphertext.
  2. The receiver computes S = dR.
  3. The same shared secret is obtained because dR = rQ.
  4. XORing again with the secret recovers the message.

Attack

In a real ECC system, recovering d from Q=dG is infeasible. In this toy implementation the private key is limited to a very small range. An attacker can therefore try every possible value of d until the correct public key is found. This attack is possible only because the key space is tiny.
