What the assignment asks us to do

Exercise 1 asks for two numerical interpretations of the same integral. The Riemann method divides the domain into vertical strips. The Lebesgue-inspired method divides the range into value layers, estimates the measure of each preimage, and sums “height × measure”. We must compare accuracy, convergence and running time, and include pathological functions.

Exercise 2 asks for an efficient implementation of the standard normal CDF, a comparison with trusted values, and an explanation of why its integral is not elementary even though it has exact representations through the special function erf.

Theory needed for Exercise 1

Riemann integral

For a bounded function on [a,b], divide the domain into n intervals of width Δx. A midpoint sum is

Rn = Σ f(a+(i+1/2)Δx)Δx.

If these sums approach the same limit as the mesh tends to zero, f is Riemann-integrable. A bounded function is Riemann-integrable exactly when its discontinuities form a set of measure zero.

Lebesgue integral

For a non-negative measurable f, partition its values into bins. If Ej={x:yj≤f(x)<yj+1}, then a lower simple-function approximation is

L = Σ yj μ(Ej).

The program estimates μ(Ej) on a fine domain grid. Refining both the value bins and measurement grid approximates the Lebesgue integral.

What is being compared

The two methods partition different axes. Riemann accuracy depends strongly on variation in x. The layer method depends on value-bin width and on how accurately preimage measures are estimated. For ordinary integrable functions both should converge to the same integral.

Improper integrals

1/√x is unbounded at 0, so it is not Riemann-integrable in the bounded-function sense, but its improper integral exists:

∫01x-1/2dx = limε→0+∫ε1x-1/2dx = 2.

The implementation avoids evaluating the endpoint by using midpoints.

Dirichlet and Thomae

The Dirichlet function 1Q is discontinuous everywhere, so it is not Riemann-integrable. Since the rationals are countable and have measure zero, its Lebesgue integral is 0. Thomae's function is continuous at every irrational and discontinuous only at rationals, so it is Riemann-integrable, with integral 0.

Important numerical warning

A computer stores rational floating-point numbers. Naively testing “is x rational?” would therefore return true at every sample and incorrectly give 1 for the Dirichlet function. The code treats the mathematical measure of Q analytically for that example and labels the Riemann result as non-existent.

Exercise 1 - Conclusions

Regular functions

For sin(x), x², step functions, |x−0.5| and sin(x)/x, both approaches approach the same exact value. Midpoint Riemann sums are usually more accurate per operation for smooth one-dimensional functions.

Discontinuities

A finite number of jumps does not prevent Riemann integrability. Changing a function at one point, or even on a measure-zero set, does not change its Lebesgue integral and does not change a Riemann integral when integrability is retained.

Pathological difference

Dirichlet's function is the clearest difference: no Riemann integral exists because every interval has infimum 0 and supremum 1, while the Lebesgue integral is 0 because Q has measure zero. Thomae's function is less extreme: it is Riemann- and Lebesgue-integrable, both with value 0.

Efficiency

Both implementations are O(n) for one resolution. The layer method also initializes and processes value bins and needs a reliable range bound. In higher dimensions or for indicator functions, measuring level sets can nevertheless be conceptually or computationally advantageous.

Theory needed for Exercise 2

Standard normal CDF

Φ(z)=P(Z≤z)=∫−∞z(1/√(2π))e−t²/2dt.

Symmetry gives Φ(−z)=1−Φ(z) and Φ(0)=1/2, so it is enough to compute the integral from 0 to |z|.

Why no elementary formula?

Liouville's theorem on elementary antiderivatives gives a structural criterion for when an elementary function has an elementary primitive. Applied in differential algebra, it shows that e−x² has no antiderivative expressible by a finite combination of elementary functions. “No elementary antiderivative” does not mean “no exact definition”.

Error function

erf(x)=(2/√π)∫0xe−t²dt,
Φ(z)=½[1+erf(z/√2)].

erf is a special function introduced precisely to name this non-elementary integral. Computers still need algorithms, such as rational approximations, series or quadrature, to evaluate it.

Methods implemented

Composite Simpson: high accuracy for smooth integrands. Power series: term-by-term integration around 0, useful for moderate |z|. erf approximation: a fast closed numerical approximation using a short polynomial and exponential.

Final evaluation

Composite Simpson quadrature is the best transparent general-purpose method here: it converges rapidly because the normal density is smooth. The power series is mathematically direct but suffers from slow convergence and cancellation as |z| becomes large. The erf approximation is fastest and accurate enough for many applications, although a production scientific library would use carefully designed piecewise rational approximations and tail formulas.

Numerical methods remain necessary because naming the integral erf gives an exact analytical representation but not a finite sequence of elementary arithmetic operations. The special function itself must still be evaluated to a requested precision.
